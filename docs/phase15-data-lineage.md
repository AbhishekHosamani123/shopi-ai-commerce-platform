# 🔍 Phase 15N & 15O: Audit-Grade AI Data Lineage & Trust Architecture

## 1. Mathematical Data Lineage Model

To prevent AI hallucination and provide enterprise-grade auditability, every metric generated by Merchant AI Copilot is bound to a `merchant_data_lineage` record.

### Lineage Record Schema:
| Field | Type | Description |
| :--- | :--- | :--- |
| `lineage_id` | `VARCHAR(100)` | Unique lineage identifier (`lin_*`) |
| `merchant_id` | `VARCHAR(100)` | Multi-tenant merchant ID |
| `metric_name` | `VARCHAR(100)` | Metric name (e.g. `TOTAL_REVENUE`, `AOV`) |
| `metric_value` | `NUMERIC(14,2)` | Exact computed numeric value |
| `source_name` | `VARCHAR(100)` | Data origin (`Canonical Synchronized Data`) |
| `entity_type` | `VARCHAR(50)` | Table queried (`merchant_canonical_orders`) |
| `period_start` / `period_end` | `TIMESTAMPTZ` | Temporal range evaluated |
| `records_evaluated` | `INT` | Total records included in calculation |
| `calculation_formula` | `VARCHAR(255)` | Deterministic SQL formula (`SUM(total_amount)`) |
| `reconciliation_status`| `VARCHAR(30)` | Reconciliation state (`RECONCILED`) |

## 2. Trust Label Taxonomy (Phase 11 Standard)

Every AI response enforces standardized trust classification:

- `[FACT]`: Direct mathematical aggregate from canonical table (`SUM`, `AVG`, `COUNT`).
- `[AI INSIGHT]`: Statistical derivation, anomaly detection, or trend correlation.
- `[FORECAST]`: Bayesian forward projection of demand or stockout trajectory.
- `[RECOMMENDATION]`: Action item prepared for merchant human-in-the-loop review.
- `[SIMULATION]`: Synthetic scenario output generated by what-if simulator.

> **Rule**: Forecasts and simulations are **never** labeled as `[FACT]`.
